Objetivo:
  Desarrollar un sistema orientado a objetos mas robusto, 
  inegrando herencia, validacion y manejo de excepciones 
  para simular un entorno profesional

Flujo de clases: 
  En la clase Usuario defini nombre y correo, validando 
  el formato de correo y mandando una alerat si este es 
  incorrecto

Manejo de errores
  Usamos excepciones y obligamos al sistema 
  a revisar que el correo sea válido antes de dejar pasar 
  al usuario
