        Objetivo  
        Aplicar los fundamentos de la Programación Orientada a Objetos en PHP, implementando una clase con atributos privados,
        constructor y métodos de acceso, siguiendo buenas prácticas de
        encapsulamiento 

        Diferencias entre Usuario y Admin

        Clase Usuario (Base): Contiene la estructura general de cualquier usuario (nombre y correo electrónico)

        Clase Admin (Hija): Hereda la estructura de Usuario pero se especializa al implementar el método getRol(), el cual retorna específicamente la cadena "Administrador"
